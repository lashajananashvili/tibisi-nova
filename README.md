# TechZone — TBC Nova Project

ფუნქციური და ვიზუალურად დახვეწილი ვებსაიტი შექმნილი **TBC Nova**-ს კურსის ფარგლებში, **Google Anti-Gravity AI აგენტის** დახმარებით.

## 🚀 ტექნოლოგიური სტეკი
- **HTML5**: სემანტიკური სტრუქტურა (`header`, `nav`, `main`, `section`, `footer`).
- **Tailwind CSS**: სტილები CDN-ის მეშვეობით (`https://cdn.tailwindcss.com`).
- **Pure Web**: არანაირი გარე CSS ფაილები, Bootstrap ან JavaScript.

## 📁 პროექტის სტრუქტურა
- `day1/` — HTML/CSS შესავალი და მაგალითები.
- `day2/` — სტილები და განლაგება.
- `day3/` — Responsive Grid გალერეა.
- `day4/` — **მთავარი პროექტი (TechZone)**:
  - `project.html` / `index.html` — მთავარი გვერდი (Hero, Categories, Features, Footer).
  - `3d-printing.html` — 3D ბეჭდვის კატალოგი.
  - `electronics.html` — Arduino & DIY კომპონენტები.
  - `news.html` — ტექნოლოგიური ბლოგი.
  - `about.html` — ჩვენ შესახებ.
  - `contact.html` — საკონტაქტო გვერდი.
- `index.html` — გადამისამართება მთავარ გვერდზე.
